# Fonte CLIMA para Android

Fonte extraída da prévia: **Chakra Petch**.

Copie os três arquivos `.ttf` e `font_family_clima.xml` para `app/src/main/res/font/`.
Depois use `@font/font_family_clima` no XML ou `ResourcesCompat.getFont(context, R.font.font_family_clima)` em Kotlin.

Pesos usados na tela: `400` para rótulos, `500` para textos usuais e `600` para temperaturas e títulos. A fonte está sob a SIL Open Font License 1.1; mantenha `OFL.txt` junto à distribuição do app quando aplicável.
